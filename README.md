Jump & Reskin Mod for CrazyCattle3D with one new map - Chornobyl

I added jumping ability, front view camera and did a couple reskins to fit the Stalker theme (to an extent possible with this game's premise) 🙏

Controls:

SPACE - Jump

V - Toggle front view
